\section{Linear Systems and Stability}
Consider the continuous-time linear time-invariant system $\dot{x}(t) = A x(t) + B u(t)$, where $A \in \mathbb{R}^{n\times n}$.
The system is asymptotically stable if and only if every eigenvalue $\lambda_i$ of $A$ satisfies $\operatorname{Re}(\lambda_i) < 0$.
\begin{equation}
  \int_{0}^{\infty} e^{A^{\top} t} Q\, e^{A t}\, dt = P, \qquad A^{\top}P + PA = -Q .
\end{equation}
The transfer function is $G(s) = C(sI - A)^{-1}B + D$, with poles at the roots of $\det(sI-A)=0$.
